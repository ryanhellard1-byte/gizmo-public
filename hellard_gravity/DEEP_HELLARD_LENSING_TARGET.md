# Deep-Hellard relativistic lensing target

For an isolated approximately spherical baryonic mass M, the deep Hellard branch is

    g_H(r) = sqrt(G M a_H) / r.

Let

    V_H^2 = sqrt(G M a_H).

Then the dynamical potential is asymptotically

    Phi_H(r) = V_H^2 ln(r/r0) + constant.

If a relativistic completion has negligible gravitational slip in this regime,

    Phi approximately Psi,

so photons and slow matter respond to the same weak-field potential.

## Effective density target

The equivalent enclosed gravitating mass is

    M_eff(r) = g_H r^2 / G = V_H^2 r / G.

Therefore outside the compact baryonic source,

    rho_eff(r)
      = (1/(4 pi r^2)) dM_eff/dr
      = V_H^2/(4 pi G r^2)
      = sqrt(G M a_H)/(4 pi G r^2).

Thus the mediator/metric completion must asymptotically generate an isothermal-like
r^-2 effective density if it is to make the same potential account for both dynamics
and lensing.

## Light deflection target

For Phi=Psi=V_H^2 ln r, the weak-lensing deflection at impact parameter b is

    alpha
      = (1/c^2) integral d z partial_b (Phi+Psi)
      = 2 pi V_H^2/c^2
      = 2 pi sqrt(G M a_H)/c^2.

It is asymptotically independent of b in the pure deep logarithmic regime.

Representative baryonic masses for a_H=1.12e-10 m/s^2:

- 1e9 Msun:  v_flat about 62 km/s,  alpha about 0.056 arcsec
- 1e10 Msun: v_flat about 110 km/s, alpha about 0.176 arcsec
- 1e11 Msun: v_flat about 196 km/s, alpha about 0.556 arcsec
- 1e12 Msun: v_flat about 349 km/s, alpha about 1.758 arcsec

## Scope

This is a required weak-field target, not a proof that the current Hellard architecture
produces it. Real galaxies are nonspherical, transition out of the deep regime, and can
have external-field/environmental effects. Cluster lensing is an additional independent
constraint and may require physics beyond the galaxy-scale branch.
