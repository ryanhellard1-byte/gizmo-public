# Hellard relativistic completion v0.1

## Goal

Embed the nonrelativistic Hellard causal spectral-dominance law inside a relativistic tensor-vector-scalar scaffold that already satisfies the two hardest external requirements:

1. luminal tensor gravitational waves;
2. a relativistic metric sector capable of lensing and cosmology.

This document deliberately treats Skordis-Zlosnik-type aether-scalar-tensor gravity as prior art and as a scaffold, not as a Hellard discovery.

## Minimal fields

Use:

- Einstein-frame metric g_ab;
- unit timelike vector A^a with A^a A_a = -1;
- scalar phi;
- physical metric gtilde_ab to which ordinary matter and photons couple universally;
- a scale-free continuum of auxiliary memory variables M_lambda associated with the preferred aether flow.

A schematic action is

S = S_EH[g] + S_A[g,A] + S_phi[g,A,phi] + S_mem[g,A,phi,M_lambda]
    + S_m[gtilde, psi_m].

The tensor-vector-scalar coefficients must be restricted to a known luminal-GW branch rather than refit independently.

## Covariant memory channel

Define the derivative along the aether congruence

D_A = A^a nabla_a.

For each lambda > 0 define a retarded memory field by

D_A M_lambda + lambda M_lambda = lambda X,

where X is a covariant low-acceleration driver constructed from the weak-field scalar/aether sector.

The continuum measure is d ln lambda, so no preferred memory time is introduced.

The higher-order scale band is generated by derivatives with respect to ln lambda,

B_lambda = (partial_ln_lambda^2 - partial_ln_lambda) M_lambda.

For a stationary weak-field harmonic mode this reduces to the previously derived
normalized kernel

K2(x) = 4 x^4 / (1+x^2)^3

and therefore gives fast-to-slow leakage proportional to R^-4.

## Nonrelativistic matching condition

The relativistic field equations must reduce, for quasistatic weak fields and slow massive bodies, to the frozen candidate relation

a mu_H = g_N

with the isolated limit

mu_H -> mu(a/a_H),
mu(x)=x/sqrt(1+x^2),

and a_H approximately 1.12e-10 m/s^2.

The environmental response must be determined by the causal memory bandpower rather
than by a local scalar curvature threshold.

## Lensing condition

Matter and photons couple to the same physical metric gtilde_ab.

In the weak-field line element

ds_tilde^2 = -(1+2 Phi) dt^2 + (1-2 Psi) dx^2,

massive-particle dynamics is controlled primarily by Phi and lensing by Phi+Psi.

A viable Hellard completion must enforce, in the galaxy regime, enough equality between
the dynamical and lensing potentials that the same baryonic system that fits rotation
curves also produces the observed lensing signal. A pure modified-inertia matter action
with an otherwise baryon-only Einstein metric fails this requirement and is excluded.

## GW requirement

The tensor sector must remain on a branch with

c_T = c

identically, not merely approximately at one background value.

The Hellard memory sector therefore must not introduce operators that alter the
principal two-derivative tensor kinetic terms.

## Stability requirement

Before any relativistic Hellard completion can be called viable it must pass:

- no tensor ghost;
- no vector ghost;
- no scalar ghost in the background being used;
- positive or otherwise controlled Hamiltonian for the memory continuum;
- hyperbolic/causal initial-value equations;
- no gradient instability across the galaxy/Solar-System interpolation;
- GR recovery in screened/high-acceleration environments.

## Novelty boundary

Not novel:

- relativistic MOND tensor-vector-scalar scaffolds;
- luminal-GW MOND branches;
- continuum scale-invariant baths;
- causal retarded memory in open systems.

Potentially Hellard-specific:

- causal scale-localized acceleration spectrometer used as the MOND activation variable;
- higher-order R^-4 internal-mode effacement;
- spectral-dominance suppression of low-acceleration subsystems;
- joint prediction of galaxy RAR plus near-Newtonian local wide binaries from one
  acceleration scale without an extra fundamental clock.

## Current fatal unknown

The scalar/aether invariant X and its nonlinear coupling to S_mem have not yet been
derived in a way that simultaneously proves:

1. the exact Hellard nonrelativistic closure;
2. luminal tensor propagation;
3. healthy scalar/vector constraints;
4. correct lensing potential;
5. viable cosmological perturbations.

Until those are derived, this is an architecture, not a completed relativistic theory.
