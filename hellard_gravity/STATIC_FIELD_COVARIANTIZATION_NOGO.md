# No-go: naive spacetime-field covariantization of the Hellard frequency trigger

## Statement

The nonrelativistic Hellard candidate is driven by the frequency content of a body's
trajectory. A simple relativistic replacement in which the memory continuum is driven
only by a spacetime field X(x) through the aether derivative

D_A M_lambda + lambda M_lambda = lambda X,
D_A = A^a nabla_a,

does not reproduce that mechanism in a stationary galaxy.

## Reason

In an approximately stationary galactic spacetime adapted to the preferred/aether frame,

D_A X approximately 0

for any driver X built only from the stationary metric, scalar, vector, or their local
invariants.

The memory channels therefore settle to a static value and do not resolve the orbital
frequencies of stars moving through that field.

But the nonrelativistic Hellard mechanism distinguishes:

- a star's slow Galactic orbital mode;
- a faster internal wide-binary mode;
- faster planetary/internal modes;

by their trajectory frequency hierarchy.

A static spacetime-field memory does not contain this information.

## Consequence

The trajectory-frequency Hellard mechanism cannot be reproduced by simply replacing
d/dt with A^a nabla_a on a local gravitational field.

Any faithful relativistic completion must put the memory on one of:

1. matter worldlines;
2. a phase-space distribution f(x,p);
3. a dynamically equivalent set of matter-flow variables capable of representing
   multiple streams.

For galaxies, option 2 is the natural covariant continuum description because a
collisionless stellar system is multi-stream and cannot be represented by one unique
four-velocity field u^a(x).

## Lensing implication

A pure worldline modification still does not modify photon lensing. Therefore a complete
theory must also make the memory/phase-space sector contribute to the gravitational field
equations or to the universal physical metric.

This no-go rules out the simplest field-only relativistic embedding while leaving a
phase-space completion open.
