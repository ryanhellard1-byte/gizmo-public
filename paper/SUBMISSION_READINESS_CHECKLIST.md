# Submission readiness checklist

Target candidate: Physical Review Applied regular article.

## Completed
- [x] Self-contained finite-dimensional theorem statement.
- [x] Exact fixed-D correction formula separated from the class-envelope theorem.
- [x] Sharpness construction included.
- [x] Perfect-correction rank and strength thresholds stated with the important class-envelope vs fixed-D distinction.
- [x] Physical power-normalization identity included.
- [x] Lorenz-Mie specialization included.
- [x] Tail-robust finite-modal extension included.
- [x] Broadband corollary included.
- [x] Hardware-factorization interpretation included.
- [x] Numerical verification described as evidence rather than proof.
- [x] Limitations stated explicitly.
- [x] Data/code availability section included.
- [x] Substantive AI-assistance disclosure included.
- [x] No claim of universal historical priority.

## Must be completed before external submission
- [ ] Human author name and affiliation inserted.
- [ ] Every equation independently checked line-by-line by the human author or an independent qualified reviewer.
- [ ] Bibliography completed with exact author lists, titles, journals, volumes, pages, years, and DOIs.
- [ ] Generalized matrix-nearness citation verified exactly.
- [ ] Electromagnetic degrees-of-freedom citations verified exactly.
- [ ] Scattering/operator-bound literature expanded so the relationship to prior energy-conservation bounds is explicit.
- [ ] Active-cloaking literature expanded to distinguish source count, multipole order, and effective operator rank.
- [ ] Mie sign/scattering convention checked against at least one independent textbook or code convention and described clearly enough to avoid S-matrix convention ambiguity.
- [ ] Verification scripts rerun from a clean environment with seeds and dependency versions recorded.
- [ ] One independent reproducer, ideally a physicist/applied mathematician not involved in derivation, attempts to break the proof and rerun the Mie result.
- [ ] Figures added: phase diagram in (rank,strength), Mie r_min vs ka, and numerical verification residual/error plot.
- [ ] Abstract tightened after figures/results finalized.
- [ ] 100-word Physical Review Applied justification prepared if that journal remains target.
- [ ] Cover letter prepared without priority hype.
- [ ] PDF compiled from the exact repository commit intended for submission.

## Claims permitted now
- The finite-dimensional theorem is proved under its stated assumptions.
- The passive-class lower envelope is sharp within that model.
- The Mie identity is an exact consequence of the adopted partial-wave normalization and standard extinction formula.
- Targeted literature searches have not identified an equivalent combined theorem.

## Claims not permitted yet
- 'First ever law of invisibility.'
- 'Universal law of physics.'
- 'Proven historically novel.'
- 'Guaranteed realizable cloak.'
- Interpreting the Frobenius budget B or P_K directly as watts without an experimentally calibrated hardware map.

## Recommended paper title
**Sharp Rank-Strength Resource Bounds for Active Electromagnetic Scattering Cancellation**

The Hellard name can be used internally for the theorem while peer review determines whether an eponym is scientifically appropriate. The paper title should describe the result rather than assert priority.
